Бұл — SözQorBot деп аталатын қазақ тілі сөздік қорын дамытуға арналған чат-бот веб-қосымшасы (HTML/CSS/JavaScript).
Негізгі мазмұны:
Бот оқушыларға мына бөлімдер бойынша көмек береді:
	1.	Диагностика — синоним, антоним, эпитет тапсырмалары
	2.	Сөз мағынасы — мағына, синоним, антоним, мысал сөйлем (жылдам, байтақ, парасат т.б.)
	3.	Фразеологизмдер — «төбесі көкке жету», «ит өлген жер» т.б. тіркестер
	4.	Мәтінмен жұмыс — оқылым мәтіні бойынша тапсырмалар
	5.	AI-промпт — ChatGPT-ке промпт жазу тапсырмасы
	6.	Көне сөздер — садақ, кіреуке, алдаспан
	7.	Бағалау критерийі — өзін-өзі бағалау
Техникалық тұрғыдан:
	•	Таза HTML + CSS + JavaScript (фреймворксіз)
	•	localStorage арқылы чат тарихын сақтайды
	•	Чатты .txt файл ретінде жүктеп алу мүмкіндігі бар
	•	Сұлу дизайн — градиент, blur эффекттері, анимация
